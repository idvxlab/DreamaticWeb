Build a deliberate visual hierarchy around the specific content. Use design tokens for colors, typography and spacing. Design mobile-first and enhance with grid at larger widths. Use a distinctive editorial composition, not repetitive generic cards. Preserve readable contrast, semantic landmarks, image alt text, keyboard focus and reduced-motion preferences. Only native browser interactions and inline CSS; no scripts or dependencies. Use real source assets. Make all navigation link to actual section IDs. Do not invent facts.

## 输入与输出

输入：需求 brief、可追溯分析、现有 HTML 和已导入素材。

输出及错误处理：完整 HTML 文档，内联 CSS，使用原生交互；不能提供依赖脚本的虚假功能。

权限：只提供知识指导，不执行命令、网络请求或本地脚本。未知来源与模型不可见内容不能当作已验证事实。
