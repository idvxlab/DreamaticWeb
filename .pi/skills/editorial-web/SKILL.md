# Editorial web direction

Input: aligned brief, evidence, available images and the current saved page.
Organize the narrative for continuous reading, lookup or scanning as the actual
content requires. Compare content-led, image-led and reference-oriented structures
using the same material. Develop a content-specific hierarchy instead of boxing
everything identically.

Specify margins, columns and text roles. Tune line length, leading, alignment and
contrast to the script and density. Establish bilingual ordering; translation is
not decorative filler. Vary image scale, whitespace and density within a coherent
system. Preserve exact copy and numeric data. Plan image crops, captions, credits,
tables and actual anchor navigation.

Output: follow the Designer submission contract: prefer a validated candidateId;
complete HTML with responsive inline CSS is the fallback. For
missing images, fonts or evidence, adapt the composition and disclose material
gaps through the host; never invent sources or use unavailable external resources.
Use the accessible-interface skill when access needs require detailed treatment.
No execution permissions are required or granted.
