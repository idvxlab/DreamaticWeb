# An extraordinary effect still ships as a usable page

Keep default content visible before initialization. Enhancement should attach to an already coherent layout, not replace an empty page with an all-or-nothing script. Detect optional APIs and context creation; preserve a meaningful static or lower-cost scene if they fail.

Pause nonessential work when offscreen or hidden. Retain a user's pause state through those transitions. Reduce spatial movement for reduced motion, and keep all content and actions understandable. Touch users receive a deliberate interaction instead of an unavailable hover effect.

Bound draw resolution, geometry, filter area and concurrent animation. Prefer one strong focal moment to many competing systems. Smoothness claims require observation on the target device; a software-rendered desktop probe is not a phone performance benchmark.

The finish includes timing, interruption, state consistency, typography and color in every frame. Inspect actual early, focal and settled frames; repeat actions and resize the scene. Compare generation output, accepted markup, editor round trips and final preview/export if the effect changes between them. Those are external testing tasks, not extra production review agents.

Ask whether the visual belongs to the subject, can be understood without a tutorial and makes a meaningful difference when removed. A technique name, an animation declaration and a large block of JavaScript do not establish that the requested effect was delivered.
