# Signature motion without an assumed engine

Select one material recipe and carry the same timing language through its supporting states. Native animation and rendering can express the same visual intention as a framework engine, but an unimplemented library call cannot.

## Kinetic type and reveal

Keep the meaningful heading as real text. Decorative echoes are separate aria-hidden elements. Build an entrance from cropping, scale/rotation, spacing and occlusion rather than fading every line identically. Use bounded stagger and a readable landing. Avoid rebuilding the same DOM on every animation frame.

## Sticky chapter stage

Keep a visual stage sticky within a longer narrative section. Derive normalized progress from the section's actual dimensions. Map that one value to the scene's depth, light, crop and chapter state. Cache layout measurements on resize; coalesce scroll updates into one scheduled frame. Use shorter travel on phones. Text and product details remain readable without the driver.

## Spatial assembly

Use a perspective parent with distinct planes. Establish the silhouette first, then choreograph the primary assembly, secondary light/shadow and a restrained idle state. Keep labels on a readable plane. Drive pointer influence as a bounded modulation of the scene, not a separate effect competing with the main motion.

## Shared-element continuity

For an existing element changing layout, measure its old and new bounds around a single state change. Animate the inverse translation/scale back to the new layout (FLIP). Keep the semantic element and focus meaningful, and cancel/reconcile any old animation when the state changes again. Do not require a multi-page router for a same-document state change.

## One scene clock

Time-driven visuals share one clock. A requestAnimationFrame loop supplies elapsed time to all procedural layers; native animations can use a shared currentTime. Pause hidden/offscreen work, reset the previous timestamp when resuming and cap large elapsed steps after suspension. A user pause state remains authoritative after visibility changes.

Strong motion has a designed idle state or a deliberate settled composition. Do not add random wobble solely to register motion. External playback checks should compare early, focal and final frames, repeat the interaction and inspect reduced-motion/touch paths.
