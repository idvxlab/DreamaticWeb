# Help visitors understand and compare products

Group products by useful shopping distinctions found in the facts. Product entries should expose identity, distinguishing attributes, supplied price/currency and usable media. Detail sections should retain specification relationships, variants, conditions and applicable delivery/return information without inventing policy.

Use comparable fields for listings and aligned tables where comparison matters. Keep product images legible and uncropped when shape, markings or included components are important. Associate variant media only when the source supports the match. Include supporting video with native controls when available.

Only implement search, sorting, filters, cart state and checkout when the environment can support their real behavior. In a static script-free catalog, use category anchors, product detail disclosures and a provided external purchase/contact destination. An internal anchor labeled "View details" is honest; a dead "Pay now" is not. Do not fabricate stock counts, reviews, discounts or payment confirmation.

Give dense specifications a readable mobile layout and preserve keyboard access to details and actions. Reuse product components and brand tokens across the catalog. For edits, update affected products, attributes or sections without rebuilding unrelated listings.
